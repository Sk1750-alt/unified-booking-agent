Unified Booking Agent

An Intelligent Multi-Platform Agent using Model Context Protocol (MCP)

Problem Statement 3 Backpackers' Bytes Hackathon 2026

1. Executive Summary

The Unified Booking Agent is a high-performance, agentic search system built to simplify the fragmented travel booking ecosystem. By leveraging the Model Context Protocol (MCP), it provides a standardized interface to query multiple booking platforms (Real Booking.com API + Mock Platforms) simultaneously. It parses natural language queries, normalizes diverse data sources into a single schema, and uses an intelligent recommendation engine to select and explain the best options for the user.

2. Problem Statement

Today's travel search is scattered across Booking.com, Airbnb, and various other sites. Users must manually compare prices, cancellation policies, and ratings across tabs. AI assistants often lack structured tools to interact with these platforms reliably. Our goal was to build a single, intelligent agent that abstracts these platforms behind a unified protocol (MCP).

The system is highly modular. The main.py receives user input, passes it to the NLPParser for extraction, and then invokes the MCPServer tools. The server reaches out to individual Platform Adapters which return data in a Normalized Schema.

5. Intelligent NLP Mechanism

Our NLP system uses sophisticated Regular Expressions (Regex) and keyword matching to identify user intent without the latency of an LLM call.

  • Destination Extraction: Recognizes 100+ Indian cities and international hubs.
  • Constraint Parsing: Identifies budget (e.g., "under Rs. 5000"), guest counts, and dates.
  • Strategy Inference: Dynamically switches between Cheapest, Highest Rating, Best Value, and Flexible Cancellation based on user keywords.

6. File-wise Breakdown

Backend Core

  • main.py: The FastAPI "Brain" - connects the UI to the MCP tools.
  • mcp_server.py: Implements the 4 MCP tools (Search, Details, Rank, Select).
  • nlp_parser.py: The extraction engine using advanced Regex.
  • recommendation.py: The logic layer that scores and explains results.
  • run.py: Production-ready startup script.

Platform Adapters (Standardized Layer)

  • platforms/base.py: Abstract base class + Unified Listing Schema.
  • platforms/mock_airbnb.py: Simulated P2P rentals with global dynamic generation.
  • platforms/mock_booking.py: Simulated hotel inventory.
  • platforms/booking_com.py: Real-world integration via RapidAPI.

Frontend (Premium UI)

  • static/index.html: Glassmorphism chatbot structure.
  • static/styles.css: Modern dark-theme styling + responsive design.
  • static/app.js: Asynchronous interaction with the FastAPI backend.

7. Intelligent Selection Logic

The recommendation engine calculates a "Best" option using four unique strategies:

Best Value Score: Rating / (Price / 1000)

This formula allows the agent to find the perfect middle ground between high quality and low costs, which is the most common user preference.

8. Explainability Features

For every recommendation, the user receives a detailed explanation in plain English:

- "Selected as the Cheapest option at ₹2,100/night."
- "Evaluated 12 options across MockAirbnb, MockBooking, and Booking.com."
- "Meets your requirement of 'Free Cancellation'."
