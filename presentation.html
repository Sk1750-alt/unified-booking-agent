🏨 Unified Booking Agent

Multi-Platform Accommodation Search using MCP

Problem Statement 3 | Backpackers' Bytes Hackathon 2026

MCP Protocol Multi-Platform AI-Powered Explainable

The Problem

Travel Booking is Fragmented

  • Users open 5+ tabs (Booking.com, Airbnb, Agoda...)
  • Manual comparison is time-consuming
  • No unified view of all options
  • Hard to explain "why" one option is best

💡 What if there was a single agent that could search, compare, and explain?

Our Solution

One Agent, Multiple Platforms, Intelligent Recommendations

User Query
→
NLP Parser
→
MCP Server
→
Platform Adapters
→
Recommendation

✅ Natural Language Input

"Find cheapest hotel in Mumbai for 2 guests"

✅ Unified Response

Best option + explanation + all options

Key Features

Feature Implementation
MCP Server 4 tools: search, details, rank, select_best
Multi-Platform 3 platforms (1 real API + 2 mock)
Data Normalization Unified Listing schema across all sources
Intelligent Selection 4 strategies: cheapest, rating, value, flexible
Explainability Full reasoning for every recommendation
Pan-India Support 100+ Indian cities recognized
